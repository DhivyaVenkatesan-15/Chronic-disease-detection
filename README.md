# Chronic-disease-detection
Project Overview

This project is a Machine Learning-based healthcare prediction system developed to analyze blood-related health parameters and predict the likelihood of chronic disease. The system uses a Kaggle dataset containing clinical features such as Red Blood Cell (RBC), White Blood Cell (WBC), and other relevant blood parameters. The dataset is explored, preprocessed, and analyzed to identify patterns associated with chronic disease conditions.

Objective

The primary objective of this project is to build a predictive machine learning model that can analyze patient blood parameters and classify whether a chronic disease condition is likely to be present or not.

Key Features

Exploratory Data Analysis of the healthcare dataset
Data preprocessing and feature analysis
Analysis of RBC, WBC, and other clinical parameters
Machine Learning-based disease classification
Model evaluation using appropriate performance metrics
Prediction of chronic disease presence based on input health parameters

Technologies Used

Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Jupyter Notebook

Dataset

The dataset used in this project was obtained from Kaggle and contains relevant clinical and blood-related parameters used for machine learning-based disease prediction.

#Workflow

The project follows a structured machine learning workflow, including data collection, exploratory data analysis, data preprocessing, feature selection, model training, model evaluation, and disease prediction.
